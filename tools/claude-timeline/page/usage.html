Reading the numbers

  • Cost is what the same use would cost at Claude's API prices, worked out by ccusage. It isn't a bill: the subscription is a flat price.
  • Most tokens are cache reads: Claude re-reads the conversation so far on every turn, at about a tenth of the normal price. That's why the token totals look huge next to the cost.
  • Who's who is by the folder a chat ran in: chats in parth_project are Parth's, everything else is Mridul's, and test runs in temporary folders are "Other". Both use one laptop account, so it's by folder, not by person.
  • The record starts with the oldest chats still on the laptop when it began (4 Nov 2026). Anything older had already been deleted.
