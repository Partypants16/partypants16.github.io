# Apex Dash: credits and licences

Everything in the published game ("Apex Dash", built with `npm run build:public`) is listed
here. This file is copied into that build as `CREDITS.txt`.

## Made for this game, in code (no outside files)

Everything below is generated by scripts in this repository. Nothing was downloaded, traced or
made with AI image or audio generators.

| What | Made by |
|---|---|
| Ground, wall, building, water and lava textures; billboard ads (fictional brands) | `tools/public/visuals/` (Python: numpy noise, Pillow drawing) |
| The 10 driver portraits (Nova, Pip, Brick, Rosa, Baron Voss, Volt, Raven, Jade, Flint, Ozzie) | `tools/public/visuals/portraits.py` |
| 3D scenery (palms, trees, cacti, mushrooms, lamps, rocks, antennas...) | `src/render/props.ts` (built from Three.js shapes when a race loads) |
| Road, kerbs, start line, crowds, start gantry banner, sky | `src/render/textures.ts`, `src/render/sky.ts` |
| Music: 13 original tracks | `tools/public/audio/` (Python synthesis: `songs1.py`, `songs2.py`) |
| Engine sounds, sound effects, driver voices (wordless) | `tools/public/audio/` (`engines.py`, `sfx.py`, `voices.py`) |
| Title, logo, menus, HUD and on-screen icons | `src/` (CSS and inline SVG) |

Billboard and sponsor-band lettering was drawn with fonts installed with Windows (Impact,
Segoe UI Black, Cooper Black, Franklin Gothic Heavy, Eras Bold). Only pictures of the letters are
in the textures; no font files are included.
